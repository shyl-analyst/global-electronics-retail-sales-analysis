# 📊 Global Electronics Retail Sales Analysis

## 📌 Project Overview
Analyzes weekly sales performance for a global electronics retail store to track revenue trends, identify top product categories, and provide inventory recommendations using Google Sheets and SQL.

## 🛠 Tools & Technologies
- **Analysis & Visualization:** Google Sheets
- **Database Querying:** SQL
- **Version Control & Format:** GitHub, PDF

## 📈 Key Metrics & Focus
1. Weekly sales performance and seasonal fluctuations.
2. High-profit electronic product categories.
3. Regional store performance across global locations.
